Privacy Policy

Effective date: November 18, 2026 · Last updated: November 18, 2026

This Privacy Policy explains how ViceCityClipss (“the application”) accesses, uses, stores and protects data, including data obtained from Google APIs. The application is a private tool operated by the owner of the YouTube channel ViceCityClipss (@ViceCityClipsOFI) (“the owner”, “we”). It is used only by the owner to manage the owner's own channel and is not offered to the public.

2. Use of YouTube API Services

The application uses YouTube API Services to upload videos to YouTube. By authorizing the application, the account holder also agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. Google user data the application accesses

The application requests one OAuth scope:

ScopeWhat it allowsHow the application uses it
https://www.googleapis.com/auth/youtube.upload Upload videos to the authorized YouTube channel and manage those uploads. Upload finished Shorts with a title, description, tags, category, privacy status, optional scheduled publish time, and the “altered or synthetic content” disclosure when applicable.

When the owner authorizes the application, Google issues OAuth tokens (an access token and a refresh token). After each upload, YouTube returns the new video's ID and its upload and privacy status. The application does not request, read or store the owner's name, email address, contacts, comments, subscribers, watch history, YouTube Analytics or any data from other Google services.

Separately, to research topics, the application may query public YouTube information (such as public video titles and view counts) using an API key. That information is publicly available and is not tied to the owner's Google account.

4. How the data is used

  • OAuth tokens are used only to authenticate requests from the owner's computer to Google in order to upload videos to the owner's channel and to renew access when it expires.
  • The video ID and upload status returned by YouTube are saved in the application's local history so the owner can track which Shorts were uploaded and avoid publishing repeated content.
  • Google user data is not used for advertising, is not used to build user profiles, is not sold, and is not used to train artificial-intelligence or machine-learning models.

5. Limited Use disclosure

ViceCityClipss's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. How data is stored and protected

  • Local only. All data is stored on the owner's Windows computer. The application has no server, backend, cloud storage or database operated by us.
  • Encrypted tokens. OAuth tokens are encrypted with the Windows Data Protection API (DPAPI) under the owner's Windows user account, so the token file cannot be decrypted by other user accounts or on other computers.
  • Restricted folder. Tokens and the OAuth client configuration are kept in a folder whose file permissions allow access only to the owner's Windows account and the operating system.
  • Not published. Credential and token files are excluded from source control and are never included in published content.
  • Encrypted transport. All communication with Google uses HTTPS. The local authorization step uses a temporary loopback address (127.0.0.1) on the owner's computer with PKCE and a state check.

7. Sharing and disclosure

Google user data is not shared with, sold to, or transferred to any third party. Data is sent only to Google/YouTube, as required to perform the uploads the owner requested. If the law requires the disclosure of data, we would comply only to the extent required.

8. Retention and deletion

  • OAuth tokens are kept on the owner's computer until access is revoked or the owner deletes them. When access is revoked through the application, the local token file is deleted immediately.
  • If access is revoked from the Google Account page, the stored tokens stop working; the application then deletes or replaces them the next time it runs, and in any case the owner can delete them at any time.
  • The local upload history (video IDs, titles, upload dates and review results) is kept on the owner's computer for as long as the owner uses the application and can be deleted at any time by deleting the application's data folder.
  • Videos already uploaded to YouTube are governed by YouTube and can be managed or deleted in YouTube Studio.

9. How to revoke access

  1. Open the Google Account permissions page: https://myaccount.google.com/permissions (also reachable from security.google.com/settings/security/permissions).
  2. Select ViceCityClipss.
  3. Choose Delete all connections / Remove access.

On the owner's computer, the command node src/cli.js auth revoke also asks Google to revoke the token and deletes the local token file. After revocation the application can no longer upload videos until it is authorized again.

10. This website

This website is a static information page. It has no forms, no accounts, no cookies, no analytics and no third-party scripts or fonts, and we do not collect information through it. The hosting provider may process technical information such as IP addresses in its server logs under its own privacy policy.

The application is a private tool used only by its adult owner. It is not directed to children and does not knowingly collect information from children.
